# 04_Continuous

The continuous analyses that need more than one level, every subject pooled and each trait a
number. The per-level associations, with their own chance lines, are in each `Associate` step.

## Method

The null throughout: whole phenotype rows handed to other subjects (`shuffle_pairings()` in
`R/helpers.R`), which keeps the traits' correlations and breaks only their link to the proteome.
The protein limma t is refit for 100 such shuffles and saved for `05_Clustering` (`shuffled_t.rds`,
about 100 MB, regenerated by each run and kept out of git).

- Pathways from the ranking: per pairing and trait, proteins ranked by their limma t from
  `04_Continuous_no_group/01_Associate/01_Proteins`; fgsea and cameraPR on that ranking. Correlated proteins make set tests
  fire on any ranking, so each screen's count of sets at FDR < 0.05 is compared with the same count
  over 100 shuffles, and each set gets `set_score`, the share of shuffles with as large an |NES|.
- Sparse PLS (mixOmics): per level and pairing, every feature against all the pairing's traits at
  once, keepX 10, two components; the first-variate correlation against 200 shuffles of the trait
  rows.
- Module membership: per module and screen, the correlation of protein kME with |t|. A module whose
  core proteins carry its trait link scores high; judged against the 100 shuffles.
- STRING (v12, score >= 700, the measured proteins as background): interactions among each screen's
  top 50 proteins against the top 50 of 20 shuffles.
- Composition: the growth x strength interaction refit with the connective-tissue (magenta) and
  non-fibre (yellow) module changes as covariates, per level, beside the plain fit.

## Workbook

| Sheet | Holds |
|---|---|
| `pathway_chance` | Per screen: sets at fgsea FDR < 0.05, those cameraPR corroborates, shuffle median and 95th percentile, permutation p. |
| `pathways` | Per screen and set: NES, p, FDR, cameraPR direction and p, `camera_agrees`, `set_score`. |
| `spls` | Per level and pairing: first-variate correlation, shuffle null, p, BH, selected features, trait loadings. |
| `membership` | Per module and screen: cor(kME, abs t), members, permutation p, BH. |
| `string` | Per screen: edges among the top 50 proteins, shuffle null, p. |
| `composition` | Per feature: interaction effect and p, then with the composition covariates; BH per level, window and strength test. |
